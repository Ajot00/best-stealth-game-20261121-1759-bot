EMBERWICK HEIST is a top-down 2D stealth game for the “Make the best stealth game” bounty, built from `main.ts` and the `game/` folder. Steal three relics across three levels and reach the skylight exit unseen, slipping past guards’ vision cones with shadow cover and a decoy coin. The game is deterministic and uses no network.

## Run

Run `node main.ts` to copy the game to the output directory and build the dossier. To play locally, run `node serve.ts`; it serves the game on port 8080.
